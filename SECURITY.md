# Security Policy

This project stores your Immich API key and can create albums / add assets in your library. Never paste `.env` contents, API keys, or database dumps into GitHub issues, pull requests, or log screenshots.

The web UI has no authentication unless you set `UI_USER` and `UI_PASSWORD`. Do not publish port 8095 to the internet.

## Reporting a vulnerability

Please use [GitHub Security Advisories](https://github.com/eugene-bert/immich-auto-albums/security/advisories/new).

Do not open a public issue for security reports. You will get a response as soon as possible, and a fix will be released before any public disclosure.
